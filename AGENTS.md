# Contributor guide

Use the existing documentation as the single source of project guidance:

- [README.md](README.md): setup, dependency policy, commands, and current scope.
- [docs/architecture.md](docs/architecture.md): contracts, resources, and storage.
- [docs/security.md](docs/security.md): trust boundaries and operational limits.
- [docs/ci.md](docs/ci.md): required checks and hosted verification.

Update those documents when behavior changes instead of duplicating instructions
in additional per-tool or per-directory files.
